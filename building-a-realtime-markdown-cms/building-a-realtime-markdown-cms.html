1. Project Objectives

The goal was to create a zero-backend, browser-native CMS dashboard that allows technical writers to manage Frontmatter metadata directly on their local file system:

  • Zero Server Setup: Runs 100% in the browser via window.showDirectoryPicker().
  • Bi-Directional Sync: Editing metadata in the UI rewrites Frontmatter blocks directly to disk.
  • Article Bundle Support: Manages nested folder bundles (journals/2026/slug/slug.md).
