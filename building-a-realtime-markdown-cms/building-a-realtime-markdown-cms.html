1. Project Objectives

The goal was to create a zero-backend, browser-native CMS dashboard that allows technical writers to manage Frontmatter metadata directly on their local file system:

  • Zero Server Setup: Runs 100% in the browser via window.showDirectoryPicker().
  • Bi-Directional Sync: Editing metadata in the UI rewrites Frontmatter blocks directly to disk.
  • Article Bundle Support: Manages nested folder bundles (journals/2026/slug/slug.md).

3. Code Implementation

preview/dashboard.js
async function saveMetadataToFile(fileHandle, newFrontmatter, bodyContent) {
  const updatedContent = `${newFrontmatter}\n\n${bodyContent.trim()}\n`;
  const writable = await fileHandle.createWritable();
  await writable.write(updatedContent);
  await writable.close();
  console.log("Saved directly to disk!");
}
  • Recommended Best Practice: Always wrap file writes in try/catch to handle permission denials.
  • Anti-Pattern: Don't mutate file text without preserving the original body content.
