1. Introduction to Self-Attention

Self-attention allows deep neural networks to weigh the contextual importance of different tokens in a sequence:

Attention(Q,K,V)=softmax(QKTdk)V\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)VAttention(Q,K,V)=softmax(dk​​QKT​)V
  • Query (QQQ): What the current token is searching for.
  • Key (KKK): The label vector of candidate tokens.
  • Value (VVV): The actual information payload transferred.

2. Multi-Head Attention Implementation

models/attention.py
import torch
import torch.nn as nn
import math

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model: int, n_heads: int):
        super().__init__()
        self.d_model = d_model
        self.n_heads = n_heads
        self.head_dim = d_model // n_heads

        self.q_proj = nn.Linear(d_model, d_model)
        self.k_proj = nn.Linear(d_model, d_model)
        self.v_proj = nn.Linear(d_model, d_model)
        self.out_proj = nn.Linear(d_model, d_model)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        B, N, _ = x.shape
        q = self.q_proj(x).reshape(B, N, self.n_heads, self.head_dim).transpose(1, 2)
        k = self.k_proj(x).reshape(B, N, self.n_heads, self.head_dim).transpose(1, 2)
        v = self.v_proj(x).reshape(B, N, self.n_heads, self.head_dim).transpose(1, 2)

        scores = (q @ k.transpose(-2, -1)) / math.sqrt(self.head_dim)
        attn = torch.softmax(scores, dim=-1)
        out = (attn @ v).transpose(1, 2).reshape(B, N, self.d_model)
        return self.out_proj(out)

3. Key Architectural Best Practices

  • Recommended Best Practice: Always scale dot-product attention by 1dk\frac{1}{\sqrt{d_k}}dk​​1​ to prevent vanishing gradients.
  • Anti-Pattern: Don't omit layer normalization before feed-forward blocks in deep networks.
