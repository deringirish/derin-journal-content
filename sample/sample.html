3. Overlapping / Interleaving (improper nesting – may render differently)

Bold starts, Italic starts, Bold ends, Italic ends (invalid overlap)

bold italic bold? italic? → typical render: bold italic bold? italic? becomes bold with italic part?

Actual markdown: **bold *italic** italic?* – this is often parsed as bold with italic inside but may break.

We'll write specific overlapping patterns:

Pattern A: `**bold *italic** bold?*`

bold italic bold?
Expected: maybe *bold italic then italic? Actual varies.

Pattern B: `*italic **bold** italic*` (valid)

italic bold italic

Pattern C: `~~strikethrough **bold**~~` (valid)

strikethrough bold

Pattern D: `==highlight *italic*==` (valid)

highlight italic

Overlap with code and highlight: `**bold `code`**` – code interrupts.
