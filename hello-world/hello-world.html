sample heading

2. Paragraphs

I really like using Markdown.

I think I'll use it to format all of my documents from now on.

Best Practice: Do not indent paragraphs with spaces or tabs.

3. Line Breaks

This is the first line.
And this is the second line.

Alternatively, you can use the <br> tag, but that's HTML.

Best Practice: Use two trailing spaces at the end of a line.

4. Emphasis

Bold

I just love bold text.
I just love bold text.
Loveisbold

Best Practice: Use asterisks ** for bold, especially inside words.

Italic

Italicized text is the cat's meow.
Italicized text is the cat's meow.
Acatmeow

Best Practice: Use asterisks * for italic, especially inside words.

Bold and Italic (combined)

This text is really important.
This text is really important.
This text is really important.
This text is really important.
This is reallyveryimportant text.

Best Practice: Use three asterisks *** for combined emphasis.

5. Blockquotes

Single Blockquote

Dorothy followed her through many of the beautiful rooms in her castle.

Multiple Paragraphs

Dorothy followed her through many of the beautiful rooms in her castle.

The Witch bade her clean the pots and kettles and sweep the floor and keep the fire fed with wood.

Nested Blockquotes

Dorothy followed her through many of the beautiful rooms in her castle.

The Witch bade her clean the pots and kettles and sweep the floor and keep the fire fed with wood.

With Other Elements

The quarterly results look great!

  • Revenue was off the chart.
  • Profits were higher than ever.

Everything is going according to plan.

Best Practice: Put blank lines before and after blockquotes.

6. Lists

Ordered Lists

  1. First item
  2. Second item
  3. Third item
  4. Fourth item

Numbers need not be sequential, but must start with 1:

  1. First item

  2. Second item

  3. Third item

  4. Fourth item

  5. First item

  6. Second item

  7. Third item

  8. Fourth item

Nested Ordered Lists

  1. First item
  2. Second item
  3. Third item
    1. Indented item
    2. Indented item
  4. Fourth item

Best Practice: Use periods (.) as delimiters, not parentheses.

Unordered Lists

Using dashes:

  • First item
  • Second item
  • Third item
  • Fourth item

Using asterisks:

  • First item
  • Second item
  • Third item
  • Fourth item

Using plus signs:

  • First item
  • Second item
  • Third item
  • Fourth item

Nested Unordered Lists

  • First item
  • Second item
  • Third item
    • Indented item
    • Indented item
  • Fourth item

Starting List Items with Numbers (escaping)

  • 1968. A great year!
  • I think 1969 was second best.

Best Practice: Do not mix delimiters (-, *, +) in the same list.

Adding Elements in Lists

Paragraphs

  • This is the first list item.

  • Here's the second list item.

    I need to add another paragraph below the second list item.

  • And here's the third list item.

Blockquotes

  • This is the first list item.

  • Here's the second list item.

    A blockquote would look great below the second list item.

  • And here's the third list item.

Code Blocks (indented 8 spaces or 2 tabs)

  1. Open the file.

  2. Find the following code block on line 21:

     <html>
   <head>
     <title>Test</title>
   </head>

  3. Update the title to match the name of your website.

Images

  1. Open the file containing the Linux mascot.

  2. Marvel at its beauty.

  3. Close the file.

Nested Lists (mixed)

  1. First item
  2. Second item
  3. Third item
    • Indented item
    • Indented item
  4. Fourth item
